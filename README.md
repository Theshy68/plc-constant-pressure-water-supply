# 基于PLC的恒压供水控制系统设计

此目录是张倍瑞的毕业设计工作区。2026-10-13 已下载参考工程并整理原有文件；尚未完成 PLC 仿真、恒压改造或实物测试。

## GitHub 仓库

- 公开仓库：https://github.com/Theshy68/plc-constant-pressure-water-supply
- 克隆项目及固定版本的上游参考工程：

```powershell
git clone --recurse-submodules https://github.com/Theshy68/plc-constant-pressure-water-supply.git
```

已克隆但缺少参考工程时，在项目根目录运行 `git submodule update --init --recursive`。日常修改保存在 `src/working/`；上游参考工程以子模块记录固定提交，保留其独立历史。
