## 改造方向与待核对项

| 部分 | 当前参考工程 | 本课题后续需要完成 |
|---|---|---|
| 测量量 | 液位 | 压力及量程换算、标定、异常判断 |
| 执行器 | 充水／排水阀 | 可调速水泵及匹配驱动器 |
| PID | 液位控制 | 压力控制方向、限幅、参数整定和响应测试 |
| 操作 | 原HMI控制 | 核对并实现水泵手动／自动、启停和故障复位 |
| 保护 | 原作者报警逻辑 | 缺水、超压、传感器异常、过载等适配后的保护 |
| 数据 | 原项目展示 | 本项目压力曲线、测试记录和结论 |

现有任务书明确写有“PLC与变频调速”“变频器输出频率”“软启动”和“水泵过载”要求。此前设备讨论倾向1211C和低压直流水泵，并提及SB1232模拟量输出板及驱动器，尚未确定采购和兼容型号。低压直流PWM调速与交流变频器控制不同：在后续设计和正式材料修改前，需要结合指导教师要求确定路线。当前仅记录差异，未改动任务书，也未将液位工程改称为已经完成的恒压工程。

保留单泵闭环作为当前讨论的基础范围；多泵轮换暂不作为已实现功能。预算和软件版本兼容性均需进一步核对。
